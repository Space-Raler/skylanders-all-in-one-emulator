Tap a figure below to select it, then tap a slot. Tap a figure on the portal to lift it off. Double-tap a list item to put it on the next free slot.

Figures

Drop dump files or folders here to add them all at once

Dumps must be exactly 1024 bytes. They are stored on the PS5 in /data/skylanders/figures. Game progress is written back to the dump file automatically. Favorites and the game/type/folder info (taken from the folders you add, or guessed from the file name) are kept in this browser; drop a folder again any time to fill in folders for figures already on the PS5.
